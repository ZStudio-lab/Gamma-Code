01

What the tools do

Every capability is a named tool with concrete arguments — no vague “AI magic”.

read_file

Numbered lines, with optional start_line/end_line ranges. A full read of a file over 2,000 lines returns the first 500 and last 200 plus the exact range to request next — that is how long files stay inside the context budget.

> read_file src\main.cpp
1: #include <Windows.h>
2: int WINAPI wWinMain(…
  … 1,300 lines omitted — call
  read_file(start_line=501, end_line=900)

write_file edit_file

Create, overwrite, or replace an exact-match region. Ambiguous or missing matches are refused, never guessed. In ask mode every write and edit shows a unified diff before it lands.

@@ -14,6 +14,7 @@
-  user.save();
+  user.save_async();

list_dir glob grep

Folders, path patterns, and regex over contents. Results are capped — 500 paths, 200 hits — and grep hits come back as file:line: text so they are jumpable.

> grep pattern="TODO" glob="*.cpp"
src\models\user.cpp:17: TODO: debounce
src\ui\dialogs.cpp:44: TODO: i18n

run_command

Executes through cmd.exe /c. Default timeout is 60 seconds (set timeout_seconds up to an hour); stdout and stderr are captured separately.

> run_command cmd="cargo test"
stdout: 31 passed; 0 failed
stderr: (empty)

Live streaming

Assistant prose prints token by token, with markdown-aware styling. Tool-call JSON stays behind the normal spinner — so you see the model think, not its raw wire format. Esc or Ctrl+C stops the answer mid-stream.

  one call site remains▌

Compaction

Survives long sessions. Tiered: truncate old tool output → summarize old turns → hard-drop the oldest. It runs between turns, never mid-tool-call, and keeps an 80% context budget.

⏺ compacted: 27 exchanges summarized
  ≈61,000 → 9,400 tokens
02

Permission modes

The binary is fully automated by default. One flag re-enables the gates.

auto default

Hands-free.

  • reads, writes, edits, commands: run immediately
  • every call still prints a breadcrumb with its result
  • --no-yolo adds a y/N prompt for run_command

ask

Reads free. Mutations show first.

  • reads, listing, search: auto-approved
  • writes, edits, shell: y/N with the full diff or command shown
  • enable with --mode ask

plan

Read-only.

  • reads, listing, search: allowed
  • writes and commands: denied with an explanatory tool error
  • enable with --mode plan

read_file · list_dir · glob · greprunrunrun

run_commandrun*promptdeny

* add --no-yolo and auto prompts for run_command too. --yolo is accepted for compatibility; running without prompts is already the default.

03

Sessions & memory

Every conversation persists per workspace and restores completely — tool results included.

On disk

%LOCALAPPDATA%\Gamma\sessions\
  Gamma-Code_2026-10-30_21-04-11.json
  Gamma-Code_2026-10-30_23-41-02.json
  …
  • one uniquely timestamp-named file per workspace
  • full restore: turns, replies, tool calls and their results
  • written after every turn — a crash loses nothing

In the flow

  • the launcher’s Sessions row lists saved conversations, newest first
  • N in the launcher starts a brand-new session instantly
  • --no-ui auto-resumes the workspace’s newest session
  • /clear deletes the file and starts fresh; one-shot -p runs stay ephemeral
  • Esc / Ctrl+C stops streaming output; truncated tool calls are never executed

The command line

05

Install

One installer. No C++ toolchain, CMake, or Visual Studio required.

irm https://zstudio-lab.github.io/Gamma-Code/install.ps1 | iex

Downloads the latest portable build, verifies its SHA-256 against a checksum embedded in the archive, then installs. Nothing else touches the network.

winget install GammaCode.Gamma

Manifest lives in the repo at installer/winget/manifest/G/GammaCode/GammaCode.Gamma/0.1.1/ and validates with winget validate.

Download installer

The installer verifies the binary’s SHA-256 against a checksum embedded in it. Trust comes from the source: it lives in this repository.

first run — gamma does the rest:

gamma

requirements

  • Windows 10 22H2+ or Windows 11, x64
  • Ollama is optional at first: gamma asks Install Ollama? [Yes/No], installs it with visible progress, and starts ollama serve
  • No model needed up front — the first run pulls the largest qwen2.5-coder that fits your RAM/VRAM (1.5b / 3b / 7b / 14b / 32b)
  • Already have models? gamma uses the newest tool-capable one automatically; --model pins a specific tag

One-shot instead? gamma -p "explain main.cpp" answers without entering the γ ❯ REPL.

Installs to %LOCALAPPDATA%\Programs\GammaCode\ and adds it to your user PATH. The uninstaller removes both again.

If Windows SmartScreen warns about the installer

Click More info → Run anyway. Gamma is an unsigned open-source binary — SmartScreen flags any installer it has no download reputation for. If you’d rather not click through the warning, use the PowerShell or Winget path instead, or verify the binary’s SHA-256 against SHA256SUMS.txt from the release.
