What the tools do

read_file

Numbered lines. Files past 2,000 lines split into head + tail with a hint to request the range you need.

> read_file src\main.cpp
1: #include <Windows.h>
2: int WINAPI wWinMain(…
  … (+1,842 lines — request a line range)
edit_file

Exact-match replacement. Ambiguous or missing matches are refused, never guessed. Every change shows a unified diff before it is written.

@@ -14,6 +14,7 @@
-  user.save();
+  user.save_async();
glob grep

Paths by pattern; regex over file contents. Capped at 200 hits, reported as file:line: text.

> grep pattern="TODO" glob="*.cpp"
src\models\user.cpp:17: TODO: debounce
src\ui\dialogs.cpp:44: TODO: i18n
run_command

Executes via cmd.exe /c — or PowerShell with --shell psh — 60-second timeout, stdout and stderr captured separately.

> run_command cmd="cargo test"
stdout: 31 passed; 0 failed
stderr: (empty)
ask_user

The model pauses and asks you directly when it needs something no file contains — a preference, a credential path, a decision.

ask: "Which branch should I
      rebase onto — main or next?"
compaction

Survives long sessions. Tiered: truncate old tool output → summarize old turns → hard-drop oldest. Never interrupts a tool call mid-flight.

⏺ compacted: 27 exchanges summarized
  ≈61,000 → 9,400 tokens

Permission modes

You decide what runs without being asked.

plan

Read-only.

  • reads, search, listing: allowed
  • writes and commands: denied with an explanatory tool error

ask default

Reads are free. Mutations show first.

  • reads, search, listing: auto-approved
  • writes, edits, shell commands: y/N prompt with the full diff or command shown

auto

Hands-free, with a floor.

  • reads, writes, edits: auto-approved
  • run_command: still prompts, unless --yolo

Install

One installer. No C++ toolchain, CMake, or Visual Studio required.

irm https://zstudio-lab.github.io/Gamma-Code/install.ps1 | iex
winget install GammaCode.Gamma
Download installer

The installer verifies the binary's SHA-256 against a checksum embedded in it. Trust comes from the source: it lives in this repository.

after install — one-time:

ollama pull qwen2.5-coder:7b
gamma

One-shot instead? gamma -p "explain main.cpp" answers without entering the γ ❯ REPL.

Gamma does not bundle Ollama; install it separately from ollama.com/download/windows.

Installs to %LOCALAPPDATA%\Programs\GammaCode\ and adds it to your user PATH. No C++ toolchain, CMake, or Visual Studio required.

If Windows SmartScreen warns about the installer

Click More info → Run anyway. Gamma is an unsigned open-source binary — SmartScreen flags any installer it has no download reputation for. If you'd rather not click through the warning, use the PowerShell or Winget path instead, or verify the binary's SHA-256 against the value published alongside each release.
